# Step 1: Gather current context (Codex read-only adapter)

Read the approved requirements, plan, repository authorities and the coordinator's review target. Identify the actual worktree, full base SHA and current source state, including untracked source. Inspect the diff and surrounding callers with native read tools or read-only shell. Never create temporary diff, claims, ticket or report files.

A branch comparison uses its merge-base. An uncommitted comparison includes the actual tracked edits and untracked source. Return missing base, inaccessible files, absent intent or empty scope as explicit limitations; do not guess a target, invoke ticket scripts or wait for a menu selection.

Keep the original claims separate from source evidence in task context; claims are not proof. The coordinator supplies already authorized source/diff paths where needed. Proceed to step-02-review.md.
